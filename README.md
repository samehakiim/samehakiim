## Praxisprojekt

### [Custom WhatsApp Floating Button](https://github.com/samehakiim/custom-whatsapp-floating-button)

Ein WordPress-Plugin mit einem responsiven Kontakt-Button. Der Button öffnet einen WhatsApp-Chat mit vorausgefüllter Nachricht. Auf dem Desktop ergänzt ein Tooltip den Button, auf Mobilgeräten bleibt die Darstellung kompakt.

**Technik:** PHP, WordPress, HTML und CSS  
[Installation und Konfiguration](https://github.com/samehakiim/custom-whatsapp-floating-button#lokal-ausprobieren)
